# 백석대학교 긱창업 플랫폼 이미지 에셋 팩

현재 확정된 홈 / 프로젝트 탐색 / 전문가 탐색 / 프로젝트 상세 방향과 업로드된 최종 시안에서 실제 콘텐츠 이미지로 재사용할 수 있는 부분을 분리한 프로토타입 에셋 팩입니다.

## 폴더

- `brand/` : 로고 및 푸터 장식
- `home/` : Hero/프로모션/보조 일러스트
- `portfolio/` : 작업물·전문가 대표 작업 이미지
- `projects/` : 프로젝트 탐색용 예시 이미지
- `demo/avatars/` : 데모용 프로필/후기 아바타
- `webp/` : 동일 이미지의 웹 최적화 WebP 버전
- `docs/assets-manifest.json` : 파일별 용도/크기/주의사항
- `docs/asset-preview.jpg` : 전체 미리보기

## 구현 시 중요한 원칙

1. 프로젝트 대표 이미지는 **선택 사항**입니다. 이미지가 없으면 카테고리 기반 CSS placeholder를 사용하세요.
2. 전문가 카드의 핵심 이미지는 프로필 사진이 아니라 **대표 포트폴리오 작업물**입니다.
3. 카테고리/필터 아이콘은 PNG로 만들지 말고 SVG 아이콘 컴포넌트로 구현하세요.
4. Hero/배너 문구, 카드 제목, 가격/기간/CTA 등 텍스트는 이미지 안에 굽지 말고 HTML로 렌더링하세요.
5. 본 ZIP의 사진/로고는 현재 시안에서 잘라낸 **프로토타입용**입니다. 실제 운영 전에는 원본 고해상도·사용권 확보 이미지로 교체하는 것이 안전합니다.

## 권장 파일 사용

- 웹 서비스 기본은 `webp/` 사용, 필요 시 PNG fallback
- 썸네일은 `object-fit: cover`
- Hero/프로모션 콜라주는 `object-fit: contain`
- 아바타는 32~40px 원형
